# 超级建筑师 · SUPER ARCHITECT

建筑与空间创作工作台，采用 React、FastAPI、SQLite 与 pywebview，使用本机 Codex / WorkBuddy 执行 AI 任务。当前内部运行时标识 `codebuddy` 对应界面规划中的 WorkBuddy，沿用已有接入。

## 当前状态

本仓库首次公开的是 **0.6.2 现有应用的自研源码快照**。以下改造正在设计，尚未实现：

- 移除工作台会员、登录、积分、租户和管理端依赖，直接进入本地工作区。
- 将依赖远端会员的创作入口接回本地业务，资料与成果保存在本机。
- 首页改为按部门划分的微缩建筑设计院，参考人物打字、走动和协作场景。

现有源码仍包含旧账号、云项目和发布模块；不能把本仓库公开理解为上述改造已经完成。完整设计见 [改造方案](docs/open-source-local-design-proposal.md)。方案确认前不提前改造应用。

## 已有源码模块

- 设计对话、任务事件、历史、附件、草稿和本地 Agent 执行。
- 项目知识、资料检索、创意画板、素材管理。

## 开发环境准备

需要 Python 3.11+、Node.js 22+；Windows 桌面壳还需要可用的 WebView2。AI 工具与专业宿主由用户自行安装、配置，账号和额度由各工具自行管理。

在 Windows 上请将检出目录、虚拟环境、依赖缓存、构建输出、临时目录及数据目录统一放在 E 盘，并在安装或运行前显式设置 TEMP、TMP、PIP_CACHE_DIR、npm 缓存和浏览器测试资料路径。不要从本仓库读取其他产品的私有安装目录来补齐资源。

Python 依赖与可选组见 `pyproject.toml`，前端依赖见 `frontend/package.json` 与锁文件。公开依赖准备流程及干净环境验收将在本地化改造中完善；当前不提供已完成复现验证的安装包。

## 首页方向

建筑设计所、规划与景观所、结构设计所、机电设计所、室内设计所、BIM 与数字技术中心，以及中央总师办评审区。部门空间是交互入口；专业计算、碰撞检查和审签等能力必须按实际接入情况标注。

人物环境动画与真实任务状态分开处理。场景提供暂停、减少动态和静态降级；AI 联网需求由本机 Agent 决定，不承诺离线模型推理。
