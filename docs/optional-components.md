# 可选组件与公开依赖缺口

本仓库公开自研源码、本地核心与原创设计院/室内编辑器，不随附参考产品安装目录中的静态包、私有技能、模型、便携运行时或商业 SDK。以下组件缺失是刻意边界，不是构建失败：核心工作台必须在它们不存在时仍能启动和保存本地数据。

| 组件 | 当前状态 | 缺失时的核心行为 | 公开替代方向 |
| --- | --- | --- | --- |
| DWG/DXF 完整查看器（`frontend/public/cad-viewer/`） | 未包含 | 应用正常启动；DXF 可用后端快速预览；DWG 入口提示安装可选查看器 | 使用允许再分发的上游查看器自行构建，或提供原创轻量查看器；不得从参考产品目录复制 |
| 完整作品汇报编辑器（`frontend/public/report-builder/`） | 未包含 | 应用正常启动；快速 HTML/PPTX/Word/Excel 导出可用 | 从公开上游固定版本构建，或实现原创编辑界面 |
| 参考技能包 / `resources/skills/` | 未包含 | 技能列表为空也能启动、对话和保存 | 用户自行导入合法技能，或使用公开示例技能 |
| 室内三维编辑器 | 已提供原创公开源码 | npm run build 自动生成，支持离线 HTML/GLB | frontend/interior-editor；Three.js MIT；无需参考资源 |
| 便携 Python/Node 运行时 | 未包含 | 使用本机已安装的 Python/Node | 由用户自行安装；发布时再单独打包 |
| 本地语义检索模型 | 未配置 | 自动回退 FTS5/子串检索 | 用户按脚本说明自行准备模型 |
| Blender / SketchUp / Rhino / Revit / AutoCAD 等宿主与插件 | 未安装/未授权 | 连接检测显示未就绪；不伪造执行成功 | 用户自行安装并授权；插件按各自许可证分发 |
| 商业 SDK / 原生桥 | 未包含 | 相关专业能力明确标注不可用 | 取得合法授权后由用户配置 |
| 语音识别/合成引擎 | 未配置 | 语音入口提示；文本任务可用 | 使用本机系统语音或公开引擎 |

## 检测与降级

- `GET /api/local/info` 返回 `optional.cad_viewer` 与 `optional.report_editor` 的可用状态和降级说明。
- 前端在缺失时使用明确的可选组件提示，不渲染不存在的 iframe，也不阻断其他页面。
- 核心健康检查、项目/会话持久化、附件、设置和本地 Agent 路径不依赖上述组件。

## 复现边界

如需复现完整专业能力，须从公开上游准备对应依赖，记录版本、来源、许可证与校验值，并在干净检出中验证。不得读取或复制 `F:/源智普道工作区/软件研发部/建筑智能工作台` 等参考安装目录的忽略资源来伪造可复现。
