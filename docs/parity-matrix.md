# 超级建筑师：能力矩阵与验收缺口（M1）

更新日期：2026-11-08（America/Phoenix）。范围：M1 本地核心改造；M2 设计院首页场景未开始，M3 独立验收未开始。

本矩阵只记录本轮工作树中实际实现和实际执行的项目。测试通过不等于历史全部能力复现，也不等于未执行的实机/浏览器验收已完成。详细命令、退出码与日志位置见项目经理报告 `reports/M1.json`。

## 状态口径

- **已验证**：本轮在实际工作树中执行命令并通过，有可复核输出。
- **代码保留/未复验**：代码路径仍在，但本轮没有完成真实外部调用或实机验证。
- **可选组件缺失**：公开源码刻意不包含参考静态包，核心以降级方式运行。
- **已退役**：对应账号/云端/管理端功能及入口已移除。
- **未开始**：属于后续阶段。

## M1 明确缺口

1. M2 设计院首页、部门入口、原创人物动画与真实任务联动未开始。
2. Codex / WorkBuddy 本轮未完成真实模型任务复验，受本机账号/额度与运行环境限制；不能以 mock 或构建成功替代。
3. 专业宿主、Blender、商业 SDK、私有技能和参考静态包未复现；公开依赖复现属于 M3。
4. 数据目录只支持启动时选择，不支持运行中热切换；需要切换时重启并指向目标目录。
5. 旧数据导入只在合成副本上验证，未接触真实用户数据。
6. 未构建安装器、未重新签名发布、未执行整套历史实机脚本。
