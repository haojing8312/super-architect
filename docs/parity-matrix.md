# 当前真实能力与缺口

本轮已完成本地化、设计院首页和原创公开室内编辑器。具体命令与验收口径见 [本地交付记录](local-delivery.md)，不以构建或工具存在宣称功能等价。

| 能力 | 本轮状态与边界 |
| --- | --- |
| 无工作台账号、本地项目/对话/设置/附件/成果 | 核心回归及真实浏览器通过 |
| 回环、同源、随机令牌、文件范围 | 自动化回归通过；不是会员登录 |
| 旧匿名/会员数据独立导入、WAL保留、失败回滚 | 合成副本验证；未处理真实用户数据 |
| 设计院部门场景与人物动作 | 原创程序化三维；可暂停、减少动态与静态降级，三种视口验证 |
| 真实任务、待用户确认、完成/失败/停止及成果 | 本地运行状态、持久问答及成果接口；无模拟数量/进度 |
| 室内底图标定、手工描绘、三维编辑与离线导出 | 公开源码构建；30项工作流和真实浏览器保存/重开/GLB通过 |
| 文档/汇报 | 本地HTML、Word、PPTX、Excel；完整参考编辑器未分发 |
| CAD | DXF快速预览可用；DWG完整查看器属可选组件 |
| Codex / WorkBuddy | 保留原有本机执行器，不新增代理；真实调用结果单独记载，模拟测试不等于真实任务 |
| 专业宿主与SDK、结构/机电计算、碰撞与审签 | 部分连接代码保留，未逐项实机验证，不以部门入口冒充已实现 |
| 会员、云项目、租户、积分、管理端及旧更新链路 | 已退役；旧安装器与签名基线未改 |

历史会员/云链路测试随退役模块删除，对应本地替代覆盖已建立。旧Rhino运维脚本不在公开源码，相关测试保留并明确跳过；本轮未将它计作通过。模型、语音引擎、商业宿主需用户自行合法准备。
