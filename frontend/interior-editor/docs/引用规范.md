# 引用、来源与许可规范

## 可以使用的来源

- 本仓库已公开的自研源码、测试和文档。
- 公开 npm 上游依赖（如 Three.js），保留其原始许可证与 NOTICE。
- 用户本次上传并绑定的底图、风格参考与任务数据。

## 禁止使用的来源

- `F:` 原工程或任何参考产品安装目录中的固定 HTML/JS、技能包、模型、字体、纹理、静态编辑器。
- 授权未核实的图片、模型、材质或商业 SDK。
- 通过 CDN、云 API 或账号服务获取的场景/模型/推理结果。
- 真实客户项目、生产数据库、会员数据或凭据。

## 来源证据

每个由识别或用户描绘得到的建筑构件都应带 `sourceEvidence`：

- `sourceFileId`：本次底图文件标识
- `sourceSha256`：本次底图哈希
- `pixelBounds`：原图像素范围
- `inferred`：明确的推断项（如 `manual-user-tracing`、`height`、`untouched-openings`）

编辑器中新增的家具不带观测证据；后端保存时会标记 `manual-user-design-addition`、`design-completion`、`not-observed-in-plan`，不得写成图上已观测。
